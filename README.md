# CIVIA

Landing page do CIVIA, um projeto de óculos inteligentes e aplicativo de acessibilidade urbana. O lema é "a cidade se adapta a você".

A ideia é ajudar pessoas cegas, com baixa visão, surdas ou com perda auditiva a se deslocar pela cidade. Os óculos captam o ambiente, o app interpreta e o aviso chega por voz, vibração ou legenda.

Esta página é a vitrine do protótipo: apresenta e "vende" a ideia, sem funcionalidade real e sem backend. O formulário da lista de espera é simulado e não guarda nada.

## Rodando

```bash
npm install
npm run dev
```

Outros comandos: `npm run build` gera a versão final em `dist/` e `npx vitest run` roda os testes.

## Tecnologias

React, TypeScript, Vite, Tailwind CSS, Motion e Lenis.
